## [Unreleased]

### Added
- Desktop terminal built with Tauri v2 and a plain HTML, CSS and JavaScript interface.
- Two entry styles ("dialects"): `amadeus` (`AN`, `SS`, `FXP`, `IG`) and `plain` (`search`, `offers`, `open`). `dialect` switches between them.
- Generated demo offers with baggage, change and refund conditions. No network access.
- Terminal commands `help`, `dialect` and `clear`; grey completion with Tab, command history with the arrow keys, Ctrl+L to clear.
- `?demo` in the address plays a short scripted session.
- MIT license and README.
